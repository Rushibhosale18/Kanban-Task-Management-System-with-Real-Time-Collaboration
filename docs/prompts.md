# Prompts

## Initial Prompt Used

The foundational instruction sets used to shape the architecture and execution logic of this Kanban System are derived from Assignment 8. The instructions clearly mandated:
- A full-stack real-time collaboration tool using PostgreSQL, Node.js, and React.
- Bi-directional WebSockets for real-time task updates to avoid page refreshes.
- Strict Authorization: Project members only.
- Specific database schema concepts including foreign keys, soft deletes, and cascading behaviors.
- File attachment handling via private routes.
- An emphasis on correct position-index calculations during drag-and-drop operations.
